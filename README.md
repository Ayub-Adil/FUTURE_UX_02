# 🦷 Dental Clinic Appointment Booking App UI

A modern and user-friendly mobile app UI designed for booking dental appointments seamlessly.  
This project was created as part of **Task 2** of my UI/UX Internship at Future Intern 🚀

---

# 📱 Project Overview

The app is designed to provide patients with a smooth and simple dental appointment booking experience through a clean mobile-first interface.

Users can:
- Login or create an account
- Browse dental services
- Select doctors/specialists
- Choose date & time slots
- Confirm appointments easily
